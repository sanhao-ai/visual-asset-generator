# 风格系统（设计系统的定义、提取与复用）

本 skill 不绑定任何预设品牌风格。风格由用户品牌决定，本文件是"如何定义/提取/复用一套风格"的框架。

## 1. 风格档案格式

每个风格存为 `references/styles/<风格名>.md`，包含五个部分：

```markdown
# 风格：<名称>

## 设计令牌（CSS 变量）
:root { --paper:; --ink:; --accent:; --accent-soft:; --line:; ... }

## 字体
- 大标题字体 + 字重 / 正文字体 / 数字与序号字体

## 标志性元素（每页至少出现 2 个）
1. 背景纹理（点阵/网格/留白）…
2. 光影装饰（弧光/渐变/几何图形）…
3. 强调手法（关键词高亮笔/下划线/色块）…
4. 页眉页脚色带 / 印章或徽标位（用户品牌元素）…
5. 卡片语言（圆角/描边/投影参数）…

## 硬性约束
- 底色明暗、emoji 数量上限、印刷物料注意事项等

## 版式骨架（16:9 演示页）
页眉 → 大标题 → 内容区 → 页脚 的层级与尺寸
```

## 2. 从用户品牌提取风格

信息优先级（从高到低）：

1. 用户直接给的品牌规范/VI 手册 → 照抄令牌。
2. 参考截图/竞品图 → 用视觉语言描述 + 取色工具提取主色，向用户复述"我从图里读到了 X，对吗"。
3. 只给了品牌色和一句话气质 → 用中性骨架 + 品牌色做 3 个变体（纹理/强调手法/字体各不同）给用户选。

**禁止让用户用语言凭空描述风格**——人描述不清，图一选就准。做法：先产出 3 个单页封面预览（HTML，同一页内容、三种风格），给用户对比选择，选中后回填风格档案。

## 3. 起步默认（用户无任何品牌输入时）

仅作为"能看"的兜底，选中正式风格后立即替换：

```css
:root{
  --paper:#ffffff; --ink:#1a1a1a; --muted:#666666;
  --accent:#2563eb; --accent-soft:#dbeafe;
  --line:#e5e7eb;
}
/* 字体：系统无衬线栈；标题 700-900 字重；数字用 tabular-nums */
/* 标志性元素：左上角色块标题条 + 底部细页脚线 + 圆角卡片(12px/1px描边/轻投影) */
```

## 4. 全形态一致性检查

风格一经确认，五种产出全部沿用同一套令牌：

| 形态 | 检查点 |
|---|---|
| 演示 PPT | 令牌变量全局生效，无硬编码色值 |
| 横版 PDF | 截图自 PPT，天然一致 |
| 竖版 PDF | 重排版仍用同一令牌（不是重做设计） |
| 长图海报 | 纵向流式但沿用配色/字体/卡片语言 |
| 视频 | 舞台 HTML 引用同一份令牌 CSS |

## 5. 印刷与移动端注意

- 浅底深字打印最稳；深色背景要打印时提醒用户油墨成本。
- emoji 在喷绘/大幅印刷易变形，印刷物料换 CSS 矢量图形。
- 长图最大宽度 1080px（微信转发不压图）；视频字幕字号 ≥ 画面高度 4%。
